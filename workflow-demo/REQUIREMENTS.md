# 自动建模全流程演示 Demo 需求规范

## 1. 核心目标
本演示旨在向领导/客户展示全自动化建模流程的便捷性与专业性。核心交互原则为“自动优先，手动可控”，通过流畅的界面引导，体现“一键式”建模的核心价值。

## 2. 核心功能路径 (User Journey)

### 阶段 1: 准备 (Configuration)
- **输入项**:
  - 模型目标描述 (文本输入框，例如：预测个人客户违约概率)
  - 文件上传 (支持 CSV/TXT 格式)
  - 训练集/测试集占比设置 (滑块，例如：80/20)
  - 目标变量 (Y) 选择 (下拉菜单，根据上传文件自动解析)
  - 模型任务选择 (分类任务、回归任务)
- **主操作**:
  - “开始建模”按钮 (触发自动化流程)

### 阶段 2: 处理 (Automated Execution)
- **展示方式**:
  - 动态进度追踪列表，按顺序执行：
    1. **数据预处理**: 自动清洗异常值、缺失值填充。
    2. **特征工程**: 智能特征筛选与衍生。
    3. **模型训练**: 自动寻优算法，对比超参数。
- **视觉反馈**: 进度条 + 状态标签 (进行中/已完成)。

### 阶段 3: 分析 (Dashboard)
- **关键数据展示**:
  - **模型效果评估**: Accuracy, F1 Score, KS, AR 等关键指标对比。
  - **变量可解释性**: 提供 IV (Information Value)、WOE (Weight of Evidence) 指标分析。
  - **业务解读**: 基于大模型的特征业务含义解释 (将编码特征映射为业务术语)。
  - **性能指标**: 训练耗时 (Time elapsed)。
  - **核心洞察**: 特征重要性可视化 (Top 10关键特征)。

### 阶段 4: 报告 (Reporting)
- **功能**:
  - 导出 PDF 报告 (模拟)。
  - “重新开始”按钮。

## 3. 视觉与技术要求
- **风格**: 科技稳重风 (极简蓝白)。
- **交互节奏**: 自动化流转为主，配合 1.5 秒的节点停留，确保演示节奏可控。
- **交付形式**: 单一 HTML 文件 (整合 Tailwind CSS 及原生 JS)，确保在任何环境下均可离线演示。
